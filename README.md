# ContactMate

A secure and scalable contact management system featuring full CRUD operations, user authentication with JWT, and an admin panel. Built with modern best practices and clean architecture.

---

## Features

- Full CRUD for managing contacts  
- JWT-based authentication and role-based authorization  
- Minimal APIs with Entity Framework Core and Fluent API for data access  
- Fluent Validation for input validation  
- Middleware for cross-cutting concerns  
- N-layer architecture following SOLID principles  
- RESTful API design  
- Frontend generated with AI using HTML, CSS, and JavaScript  
- Microsoft SQL Server as the database  

---

## Tech Stack

- Backend: ASP.NET Core Minimal API, EF Core, Fluent API, Fluent Validation, Middleware  
- Authentication: JWT Tokens  
- Architecture: N-layer, SOLID principles  
- Database: MSSQL (Code First approach with automatic migrations)  
- Frontend: HTML, CSS, JavaScript (AI-assisted)
